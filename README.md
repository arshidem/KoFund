# 🛡️ KoFund - Professional Community Funding & Expense Management

KoFund is a premium, cross-platform financial coordinator designed for communities and groups. It simplifies the process of tracking contributions, managing expenses, and keeping all members informed through a sleek, modern interface.

---

## 🚀 Key Features

### 🏢 Community Management
- **Centralized Hubs**: Create or join communities to bring members together for shared financial goals.
- **Role-Based Access**: Specialized controls for community administrators to manage members and verify contributions.

### 📅 Event-Driven Collections
- **Flexible Contribution Types**: Support for both "One-time" fixed events and "Monthly Contribution" models.
- **Progress Tracking**: Real-time progress bars and financial summaries for every event.

### 💸 Expense Management
- **Transparent Tracking**: Log event-related expenses with titles and timestamps.
- **Smart Summaries**: Live calculations of Net Balance, Total Collected, and Total Expenses for instant financial health checks.

### 🔗 Public Sharing & Web View
- **Password-Protected Links**: Securely share event status with non-app users via unique web links.
- **Member-Centric Dashboards**: A professional web interface for public viewing of "Members" and "Expenses" lists.
- **Deep Link Integration**: Seamless "Open in App" functionality for mobile users.

### 🔔 Smart Notification System
- **Automated Reminders**: Set lead times and frequencies (Daily, Weekly, Monthly) for automatic participant nudges.
- **Admin Escalation**: Automatic alerts for administrators when payments become overdue.

---

## 🛠 Tech Stack

### Frontend & App
- **Flutter (Dart)**: A single codebase powering premium experiences on Android, iOS, and Web.
- **Provider**: robust state management for real-time UI updates.
- **Lucide Icons**: Modern, consistent iconography throughout the app.

### Backend & Infrastructure
- **Firebase Cloud Firestore**: Real-time NoSQL database for instant data synchronization.
- **Firebase Cloud Functions**: Serverless Node.js backend for secure data processing and public sharing logic.
- **Firebase Hosting**: High-speed global delivery for the KoFund web platform.
- **Firebase Cloud Messaging (FCM)**: Reliable push notification delivery for reminders.
- **Firebase Authentication**: Secure user identity and session management.
